<h2><code>operating_philosophy</code></h2>
</div>

| Principle                                | In practice                                                                                                          |
|------------------------------------------|----------------------------------------------------------------------------------------------------------------------|
| **Start your journey in reality**        | Find the **real** person, problem, process, and desired outcome before choosing any pre-canned solution/model/agent. |
| **Clarity over cleverness**              | Code/writing should make the next person feel capable, not impressed.                                                |
| **Diagnose before automating**           | Map the work, find where value or quality gets lost, and fix the root constraint. The juice worth the squeeze?       |
| **Bite-size feedback loops**             | Time to ship will be impacted dramatically unless you identify the feedback loops that don't provide a benefit.      |
| **Every abstraction will be earned**     | Do the work manually. Learn where it hurts. Automate only what deserves to survive.                                  |
| **Machines will earn trust**             | Define acceptance criteria first. Require tests, evidence, provenance, visible failures, and recovery.               |
| **Complexity will pay rent**             | Every dependency, service, agent, layer, and process must justify its existence with reason as rent... Rent is due.  |
| **AI may suggest; but will never drive** | AI may propose, transform, and test. Humans own purpose, risk, relationships, exceptions, taste, and accountability. |
| **Ship, sharpen; repeat**                | Momentum creates information. Evidence improves the next decision. Decisions compound!                               |
